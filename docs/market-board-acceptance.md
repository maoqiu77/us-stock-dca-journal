# 多市场看板第一阶段验收

实现范围：独立的美股、场内 ETF、场外基金看板、自选持久化、搜索、详情状态和确定性样例降级。样例行明确标为“示例数据”，不写入旧交易账本，也不参与溢价或历史计算。

已验证：FastAPI `/api/market-board/board/{segment}` 在 canonical `8000` 返回三类结构；canonical `3000` 返回页面；前端 lint 与既有 Node 单测通过；旧数据库迁移测试通过。

未解决：公开行情、基金正式净值、ETF 份额与披露供应商尚未完成联网覆盖核验；日 K 图表与完整缓存/刷新策略仍需继续实现。AI 日历增强属于第二阶段，本阶段未实施。
