# 微信小程序方向调整设计

日期：2026-09-10。用户已要求重新规划并执行，随后明确「还没有，先完成可导入的测试版」。本设计据此直接执行本地测试版；账号注册、真机预览、审核发布不作为已完成事项。

## 方向与取舍

主交付改为微信原生小程序。现有 Expo 位于 apps/mobile，冻结为历史验证材料；不再以 Android/iOS 构建、安全原生模块或应用商店作为前置门槛。Web/FastAPI 保留本机研究能力。domain 与 ai-context 继续复用。

比较：原生 WXML/WXSS + TypeScript 共享业务包最适合当前只有页面占位的项目；Taro 会增加编译框架与 React 兼容成本；web-view 会保留网页限制并增加账号/域名依赖。选择原生方案，以 esbuild 产出 CommonJS 共享核心。

## 当前交付 W0：离线可导入测试版

四个页签：持仓、记录、复盘、设置；另有交易录入页。支持单账户 USD 美股/ETF 多头、碎股、买卖手续费、FIFO 成本与已实现盈亏。新账户现金未知、历史不完整，不展示伪造的净值、行情或收益率。用户手工输入交易日，以所输入日历日期排序，不推断时区或券商成交时间。导入范围仅本小程序版本化 JSON，不读取桌面私有数据库。

首次空账本；只有用户主动点击才载入明确标注的合成示例。交易保存前回放整个账本；作废追加修订，并对后续超卖等冲突拒绝保存。复盘为可编辑日期笔记，不冒充 AI 输出。导出备份由用户显式点击复制或分享文件；导入先校验并显示摘要，再确认覆盖，原有效数据另外保留一份恢复点。

数据以单个版本化 JSON 快照写入 wx.setStorageSync，先验证再落盘，失败不得显示成功；损坏数据不得悄悄初始化覆盖。保守上限 800 KiB（UTF-8），超限引导导出。它不是 SQLCipher/安全密钥库，不能继承原 App 加密存储承诺。无网络、登录、密钥、模型请求、券商执行或自动分享；移除小程序或清理数据可能丢失本地账本。

共享领域包使用 Intl，客户端打包必要兼容 polyfill，并以无 Intl 的隔离 JS 运行环境测试。不改动共享账本金融语义。小程序工程使用官方 project.config.json 结构，构建产物不依赖浏览器 DOM、Node 内置模块或外部 npm 安装。

## 后续 W1–W3

W1 真机内测：安装微信开发者工具，申请并配置自己的 AppID，验证 iOS/Android 保存重启、金额键盘、导入导出、错误提示、存储容量、隐私说明。游客工具调试不等于真机预览完成。

W2 网络与 AI：先确定是否需要云同步。需要时新建按用户隔离的服务端 API、wx.login 会话、HTTPS 域名/合法域名配置与权限测试；AI 密钥仅服务端保管，调用前展示发送数据范围。现有本机 API 不具备直接公网多用户部署的边界，不直接暴露。复用上下文契约，先只读解释，再实现行情来源/时间/降级标识；失败可回本地记账。云端能力按独立实施计划开展。

W3 应用：按真实功能核对小程序主体/服务类目、备案/隐私声明及微信后台当前要求，完成体验版验收后再提交审核。不能承诺有股票或 AI 功能即一定能通过审核；没有账号时不代填主体、类目或密钥。

## 验收

自动验证包含：金额精度/FIFO/超卖/作废回放、损坏数据保护/存储失败/容量、备份严格格式/确认覆盖/恢复点、笔记保存、构建运行于无 DOM/无 Node/无 Intl 的隔离上下文、页控制器录入到重启回读。工程打包静态 WXML/WXSS 并检查路由和引用。当前环境无微信开发者工具时，将编译器与真机视觉验证标记为待执行，不能用网页截图代替。
