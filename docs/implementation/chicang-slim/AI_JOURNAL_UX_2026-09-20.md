# AI 手记体验调整

## 已实现

- 分析 / 记录分区；最近会话和日历按会话聚合，原始消息保留。
- 同日追问合并，跨日按当天完成的回答展示；跨午夜的一轮归到回答完成日。
- 七列日历、星期标题、月初空位与今天入口。
- 每轮问题、摘要、行情指标、依据、风险、观察条件按顺序展示。
- 自动拼接提示词和来源默认折叠；来源类型中文化，行情时间与获取时间分开。
- 从冻结行情快照合并 K 线分段并去重，计算 MA5/20/60 与近 20 根高低点；样本不足显式说明，高低点不冒充已确认支撑压力。
- 无缺失时隐藏；个人持仓信息单独提示；结果注明本地已保存。
- 个人想法空白起草，避免复制 AI 正文后误标为用户观点。
- 快捷追问只填草稿，仍需预览和确认；删除移入更多菜单。
- 本地网关提示词要求覆盖请求项目、明确限制、条件与证据区分，并减少重复。
