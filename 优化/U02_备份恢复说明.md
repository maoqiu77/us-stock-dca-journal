# 本地备份与恢复（U02）

适用 Web 桌面端与本地 FastAPI。备份和恢复文件均为私人数据，不能提交 Git 或上传公开站点。

## 备份

页面顶部“下载数据库完整备份（不含密钥）”创建 SQLite 一致性快照，包含账本、手记、会话、不可变快照、Agent 来源/事件、量化数据、非密钥偏好、版本及 SHA-256 清单。`quant-analysis/` 的 JSON 导出作为关联文件纳入，数据库是权威数据。不会复制 `.env`、日志、PID、更新包或历史备份；配置中的 API key 会清空并清理 SQLite 空闲页。

浏览器未提交草稿与数据库不同。另点“导出所有浏览器草稿”，保留全部窗口候选、旧副本、冲突候选和未决操作 ID。不要在保存结果待核验时把导出草稿当作已入账。页面完整备份附带 theme、当前视图及引导状态三项界面偏好，保存在 `browser-local-storage.json`。更新器备份也已改用此一致性格式，其浏览器副本只采用允许的账本/界面偏好键。

## 先隔离验收，再切换

在项目根目录运行（用实际 ZIP 路径替换占位符；隔离目录必须尚不存在）：

```sh
PYTHONPATH=apps/api .venv/bin/python -m app.modules.local_backup verify /绝对路径/备份.zip --workspace /绝对路径/新的私人验收目录
```

检查清单、SQLite integrity、schema 7/8/9、账本格式、快照/会话/来源关联。schema 9 还检查判断/政策版本链、用户确认状态及原冻结快照。缺失引用、未知 schema、无清单旧 ZIP、路径穿越和校验和错误均拒绝切换。不会启动模型或写原数据库。隔离目录可能保留失败数据供诊断，请作为私人文件保管。

确认隔离结果后，先关闭本地 API（Codex 操作须征得用户同意），再运行：

```sh
PYTHONPATH=apps/api .venv/bin/python -m app.modules.local_backup restore /绝对路径/备份.zip --target /绝对路径/股票交易平台-next/storage/local
```

目标必须是专用、已有 `app.db` 的数据目录。此命令拒绝 canonical 8000 仍在监听或持有工作区运行锁的情况，不会杀进程。恢复整个数据目录；自定义 DB_PATH 不在该目录时不可用此切换命令。程序先生成隔离副本，将原目录原样移到 `local.before-restore-<ID>`，再切换；切换失败会自动恢复原目录。若进程被强制终止，`.local.restore-pending.json` 标记会阻止 API 初始化默认数据库；保持服务停止，依据其中路径还原原目录、确认后再移走标记。恢复点含原始密钥，需妥善保管。标准 `storage/local` 的恢复点、暂存目录与锁已 gitignore。自动目录切换限 macOS/Linux；Windows 可生成/隔离校验备份，但需人工离线切换。

恢复会清除旧写入回执并生成新 revision，让旧浏览器窗口重新比较候选。queued/running 等 AI 任务变为 outcome_unknown，量化任务变为 interrupted，不自动重发付费请求。重新用一键启动器启动后，核对账本与历史引用；模型配置密钥需重新设置。浏览器已有候选必须显式选择，不会静默覆盖恢复的数据库。ZIP 内的 `browser-local-storage.json` 仅保留为副本，不自动写进浏览器。

## 回退 / 损坏

保持 API 停止，将恢复后的数据目录另存，再把 `local.before-restore-<ID>` 改回原目录名。不要运行旧代码写 schema 8/9；使用兼容程序或升级前备份。损坏 JSON 不会自动回默认账本；损坏 DB 不会被删除重建。先保留原文件及 WAL/SHM，再隔离检查可用备份。无清单的历史 ZIP 只能人工检查转换，不能作为已验证的新备份直接恢复。

本轮只在临时合成目录演练；未切换或迁移真实账本。

## U07 发布候选验收边界（2026-10-04）

Windows/macOS runner 会先运行 PyInstaller 可执行文件的 `--self-check`，再验证包布局、`release.json`、SHA-256 文件和更新器的 verify-only 模式。verify-only 只解压到临时目录，不写安装目录；CI 会在合成 `storage/local` 下放置 marker，确认更新检查不会覆盖私人运行数据。

包清单必须声明 `runtimeMode: base`、`agentIncluded: false` 和 `signatureStatus`。配置 Windows 证书或 macOS signing identity 后，runner 才会签名并验证可执行文件；未配置时只生成 `unsigned_external_required` 的内部候选，不能作为公开发布或真机安装通过。真机安装、更新、代码签名凭据、macOS 公证和 Windows SmartScreen 结果必须在对应外部 runner/设备上补证据；本地收尾不会读取真实账本或执行真实切换。

## U07 发行包与离线自检

基础发行包在构建时声明 `runtimeMode: base`，不承诺内置 Agent 依赖。冻结 API 可执行文件支持 `--self-check`：在全新临时目录创建合成手记，生成并隔离恢复 ZIP，再读回正文和 schema；自检不读取当前 `storage/local`，不探测行情、模型或网络，也不会启动服务。Windows/macOS 打包工作流必须先通过该自检，再进行布局校验。

本地验收命令：

```sh
.venv/bin/python scripts/runtime/api_server.py --self-check
npm run test:api:base
npm run test:api:agent
```

`test:api:base` 与 `test:api:agent` 都使用临时数据目录；基础模式允许并明确标记可选 Agent 测试跳过，Agent 模式有任何跳过都会失败。若当前解释器不是对应环境，命令应明确失败，不自动安装或切换依赖。

## U06：判断、政策与手记版本

schema 9 在启动迁移前沿用 SQLite 一致性升级备份，新增用户确认的判断/政策版本及手记版本表，兼容已有业务归档日期表。旧手记只把当前可读正文登记为第一个已知版本，不推测此前丢失的编辑历史。完整数据库备份自动包括这些表；“我的判断与投资政策”也可单独导出一条记录的全部版本。

判断来源固定关联原回答、会话与不可变快照。原回答不可用时保留关联并显示不可用，不重新猜测正文。取消复盘保留版本。删除手记后历史正文不再从版本接口返回，新上下文仍排除该原文；旧冻结快照与已有备份沿用 U04 的保留策略，不自动擦除。

未决判断/政策保存保存在当前标签页 sessionStorage 中，刷新后可“查询原操作回执”；不会自动重发。关闭标签页前导出未决候选；数据库完整备份不包含尚未提交的浏览器候选。冲突候选不会自动覆盖最新版，可另行导出后重新核对。

回退优先停用新 UI，保留 schema 9 的读取与导出能力，不删除版本表、不降级写数据库。必须恢复升级前备份时，先分别导出新增记录和未决候选，并按前述离线流程操作。真实库 schema 9 迁移与恢复尚未验收；本次仅在临时合成库验证。
