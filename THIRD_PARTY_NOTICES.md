## TradingAgents

The Quant Analysis workspace was informed by the public role architecture and structured research workflow of [TauricResearch/TradingAgents](https://github.com/TauricResearch/TradingAgents), including specialized analysts, bullish and bearish research debate, risk review, a portfolio-manager conclusion, and structured outputs.

This project implements those ideas natively for its existing Next.js and FastAPI stack. It does not install or bundle the TradingAgents Python package, its runtime graph, or its provider dependencies. Prompts, storage, background execution, API contracts, and user interface in this repository are local implementations adapted to this project's privacy and sample-data boundaries.
