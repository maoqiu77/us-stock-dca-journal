# 动态股票轮动策略 V1.0（研究与回测）

**警告：这是研究原型，不会自动下单，也不保证30%回撤上限。请先复核实现与数据，再做模拟盘。**

## 快速运行

```bash
python -m pip install numpy pandas yfinance matplotlib
python rotation_backtest.py --start 2014-01-01 --end 2026-11-14 --first-trade 2016-01-01
```

也支持通过本地 CSV：

```bash
python rotation_backtest.py --csv prices.csv --first-trade 2016-01-01
# 去掉Z-score的消融对照
python rotation_backtest.py --csv prices.csv --first-trade 2016-01-01 --disable-z --output output_no_z
```

CSV 格式：`Date,Ticker,Open,Close`，同一天一证券一行。需要数据代码 `VOO,QQQ,BIL,NVDA,AVGO,GOOGL,MSFT,AMZN,META,MU,INTC,AAPL`。必须是统一复权口径的开盘与收盘价。

## 核心设计

- **候选池**：NVDA/AVGO/GOOGL/MSFT/AMZN/META/MU/INTC/AAPL。
- **ETF底仓**：VOO 25%、QQQ 10%，主动候选5只，单只11%上限。正常市场股票最高90%，其余进入BIL（作为SGOV的长历史代理）。
- **趋势**：收盘价高于SMA200且SMA50>SMA200，正63日、126日（分别跳过最近5、21日）动量。
- **排序**：两个动量按风险标准化，再按0.4/0.6合成，只选排名前五。已有持仓与挑战者分数差不足0.25时不替换，以减少排名噪声造成的换手。
- **波动/行业限制**：MU上限8%，INTC上限5%，直接半导体股票合计上限22%（不包含ETF间接敞口）。
- **Z分数**：log(Close)减去60日EMA(log(Close))得到残差，过去120日计算残差的滚动均值和样本标准差。Z>=2.5减到候选权重50%，Z>=3清仓；需要Z<=1解除过热锁定。Z<=-2不主动新开仓。
- **市场防护**：VOO低于SMA200，或VOO 20日年化波动高于35%，股票仓位上限45%。
- **组合回撤防护**：自本次风险周期净值峰值回撤到-12%/ -20%时，股票仓位上限60%/30%；-25%触发全仓BIL。至少冻结20个交易日，且VOO连续5天高于SMA200并有20日正收益后，重新启动风险周期；之后两段各10天的股票上限分别为35%和60%。**风险周期高水位会在恢复时重置，但报告中的历史最大回撤绝不重置。** 隔夜跳空可超过目标回撤阈值。
- **调仓频率**：每周最后交易日收盘后计算排名；风险/过热触发时允许日度处理。所有交易在**下一交易日开盘**执行，没有同日收盘前偷看信号。
- **成本和整股**：每买入、卖出方向各按10bp执行摩擦，最小交易金额75美元，常规仓位漂移不足组合净值2.5%时不再平衡（清仓与首次买入不受此约束），整股交易，先卖后买，不使用杠杆。手续费、税务和滑点在真实交易中需要替换为券商实际参数。

## 输出

- `rotation_output/nav.csv`：每日净值、最大回撤、股票风险上限、VOO/QQQ买入持有基准，以及35% VOO + 55% QQQ + 10% BIL的无成本日再平衡基准。
- `rotation_output/daily_weights.csv`：每日实盘模拟权重和现金权重。
- `rotation_output/trades.csv`：每笔交易以及模拟滑点。
- `rotation_output/signals.csv`：每周候选名单、每只股票的Z-score和过热状态（0正常/1半仓/2清仓）、组合风险状态。
- `rotation_output/metrics.json`：CAGR、MDD、零无风险利率夏普、交易次数等。

## 研究和审计要求

1. **数据严谨性**：使用复权日线，复核拆股、分红、停牌/缺失的处理。`yfinance`适于研究原型，不是审计级交易数据。该模拟把复权OHLC当作可交易合成价格，收益适配，但买卖日志里的“股数”不能直接用于真实下单；实盘应根据当时原始股价重新算股数。
2. **长历史代理**：QQQ代替较年轻的QQQM；BIL代替较年轻的SGOV，但费率、短债期限、分配款与跟踪误差不同。报告不能解读为QQQM和SGOV从2016年起的真实回测。
3. **先验存活偏差**：今天的9家候选公司是事后选定的幸存者，历史业绩会偏乐观。改进方案：用每个历史日期事先存在的可交易候选池、历史成分和退市股票。
4. **所有历史参数均为假设**：不能拿全样本最优参数直接用于2026年底交易。建议2016–2021样本内，2022–2024验证，2025–2026完全冻结样本外，再做滚动前推测试。
5. **基准**：比较VOO全仓、QQQ全仓、35% VOO + 55% QQQ + 10% BIL的简单等比组合，以及使用`--disable-z`的不含Z-score纯动量版；否则无法知道策略增加的复杂度是否真的有益。
6. **市场冲击压力测试**：单侧成本10/20/30bp；阈值2.0/2.5/3.0σ，MA150/200/250，持仓3/5/7只。重点看参数附近的宽平台表现，而不是尖峰最优。
7. **额外风险**：单只业绩公告、盘后事件、极端跳空、ETF重叠敞口及税务可以造成实际亏损显著大于设定值。回测中的止损是收盘计算、次日开盘成交，非保证价。
8. **执行环境**：请先跑模拟盘，至少检查20笔交易与输出账目。确认每一笔信号在成交前已存在，以及交易成本和剩余现金一致，再考虑实盘。

## 下一版优先级

- 增加基本面点时间数据（盈利预测修正、云业务增长），避免使用后来才公布的数据；
- 逐只检验波动集聚、过热后的续涨风险，不要直接假设+3σ可以产生正收益；
- 用组合真实协方差计算风险预算（控制科技股、半导体相关敞口），而非只控制名义权重；
- 将实际嘉信账户可交易股数与现金、分红预扣税、真实订单类型、开盘价格区间写入独立实盘适配器。
